Dependencies

Font
The Saira font loads from Google Fonts. Your browser fetches it from fonts.googleapis.com and fonts.gstatic.com, so Google receives your IP address. Google Fonts privacy
Hosting
GitHub Pages serves this site. GitHub logs each visitor's IP address for security. GitHub Pages data collection
Cookies and scripts
This page sets no cookies. One short script in the page moves the glow with your pointer or your phone's tilt and sends nothing anywhere. On iPhone and iPad, tapping the page asks for motion access, and the readings stay in the page.
